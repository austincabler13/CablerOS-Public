1. with the distributed build; or
2. through GitHub or another publicly accessible source-code hosting service.

GitHub is preferred, but another public source host may be used.

The source must:

- materially correspond to the Distributed build;
- include the CablerOS-Derived source and CablerOS-Derived build files or scripts reasonably necessary to build the Modified Version;
- include basic build instructions;
- be accessible without payment;
- require no more personal information than a normal free source-hosting account reasonably requires;
- remain available for at least one year after the last Distribution of that version; and
- support a reasonably reproducible build when practical, or otherwise a functionally equivalent build.

If the source location becomes unavailable, the distributor has 72 hours to restore compliant access or provide a replacement location. The outage is technically a compliance failure, but no penalty will be imposed solely for that outage if compliant access is restored within 72 hours.
